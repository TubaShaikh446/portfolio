# Portfolio Website

A personal portfolio website showcasing my skills, projects, experience, and professional profile.

## 🚀 About the Project

This portfolio website is designed to showcase my technical skills, projects, education, and professional information in a clean and responsive interface.

## 🛠️ Technologies Used

- ASP.NET Core
- C#
- HTML
- CSS
- Bootstrap
- JavaScript
- jQuery
- Entity Framework Core

## ✨ Features

- Responsive design
- About Me section
- Skills section
- Projects section
- Education section
- Contact section
- Clean and user-friendly interface

## ▶️ How to Run

1. Clone the repository.
2. Open the `.sln` file in Visual Studio.
3. Restore the required NuGet packages.
4. Build the project.
5. Run the application.
